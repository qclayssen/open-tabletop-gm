# Milestone 5: polish

## Goal

Make the grid easier to read and use, without changing the rules.

## Plan

- Cover and line of sight shading from the selected token.
- Simple fog of war (squares no player token can see).
- Condition badges on tokens.
- Keyboard controls: move the selection with the arrow keys, Enter to act, Escape to cancel (as on the reference page).
- Accessibility pass: focus order, screen reader labels for every square and action, reduced motion.
- Theatre-of-the-mind parity check with the display off.

## Questions for the user

- Should fog of war hide enemies the player has not seen yet, or only dim terrain?
